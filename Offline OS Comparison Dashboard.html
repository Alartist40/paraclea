NOMAD vs DoomsDay vs refugiOS

A side-by-side comparison of three open offline-first survival knowledge projects — covering installation, features, hardware, knowledge depth, and which one fits your scenario.

Name note: This dashboard compares "DoomsDay" as the project at doomsday.media — a bootable USB survival toolkit with 400+ manuals. 04

Which to Choose

You want a persistent Linux server

Always-on / homelab / network-shared

You have a dedicated machine (mini PC, old desktop, homelab server) running Ubuntu/Debian that stays powered on. You want everyone on your local network to access the knowledge base, AI, maps, and courses from their own browsers.

Best choice
Project N.O.M.A.D.
  • Docker-native: every service runs as a container, managed by the Command Center UI
  • One curl command installs Docker, DB, web UI, and all dependencies automatically
  • Guided Easy Setup Wizard lets you pick content collections to download
  • Network-accessible at http://DEVICE_IP:8080 from any device's browser
  • Automatic updates for core software, apps, and offline content on your schedule
  • RAG-powered AI with document upload — upload your own PDFs and ask questions

You want a bootable USB environment

Portable / emergency / field use

You want to carry a complete survival knowledge system on a USB stick that boots on any computer without installing anything. You need it to work in the field, during emergencies, or when traveling — with or without a host operating system.

Best choice
refugiOS
  • Boots on any PC and Raspberry Pi 3B+ — not just x86_64
  • Full Wikipedia with images + WikiMed medical encyclopedia via Kiwix
  • Offline world maps with GPS navigation via Organic Maps
  • LUKS-encrypted personal vault for your private documents
  • Local AI models from 0.6B to 14B (Qwen3, Gemma-4) via Llamafile — no GPU needed
  • AGPL-3.0 open source, actively developed, bilingual (English/Spanish)

Alternative: If you want the absolute lowest-friction USB experience and don't need maps, wiki, or open-source verifiability, DoomsDay offers a plug-and-play preinstalled USB with 400+ curated survival manuals and a pre-configured AI assistant — no setup required at all.

You want a containerized server

Docker / microservices / self-hosted

You're comfortable with Docker and want individual services you can enable, disable, or replace. You want RAG over your own documents, a vector database, and the ability to run custom containers alongside the knowledge base.

Best choice
Project N.O.M.A.D.
  • Each tool (Ollama, Kiwix, Kolibri, CyberChef, FlatNotes, Qdrant) runs in its own Docker container
  • Advanced Docker Compose deployment for manual configuration control
  • Supply Depot: one-click app catalog + support for running your own custom containers
  • NVIDIA Container Toolkit support for GPU-accelerated LLM inference
  • Container monitoring via Dozzle, helper scripts for start/stop/update
  • Qdrant vector DB enables semantic search across uploaded documents

Note: DoomsDay and refugiOS do not use Docker. DoomsDay ships as a monolithic bootable image. refugiOS installs directly on the host OS. If Docker orchestration is a hard requirement, NOMAD is the only option of the three.
