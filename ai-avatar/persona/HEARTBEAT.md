# HEARTBEAT

## Maintenance Protocol
When the Heartbeat maintenance loop triggers:
1. Load today's and recent daily interaction logs from `persona/logs/daily/`.
2. Analyze conversations for new user preferences, project goals, emotional updates, or self-improvements.
3. Consolidate durable memories into `MEMORY.md` using `memory_replace`.
4. If adjustments to demeanor or guidelines are needed, update `SOUL.md` using `soul_replace`.
5. Keep long-term memory organized, structured, and free of redundant clutter.
